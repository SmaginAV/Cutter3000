# Проверки Cutter3000 1.2.0.02

## Локальный контур

Платформа 8.3.27.2074; отдельные файловые базы с универсальной тестовой конфигурацией и конфигурацией из CF ТОиР.

- Применимость расширения и компиляция в контекстах ThinClient, WebClient, Server и ExternalConnection.
- Структурная проверка расширения: ошибок нет, два прежних предупреждения об отсутствии собственного языка. Прочитаны 68 XML, после сборки выгружены и сопоставлены все 20 BSL-модулей. Полная XSD-валидация не выполнялась.
- Четыре сценария восстановления: авария координатора после публикации, авария работника при недоступном координаторе, исчезнувшее задание без сохранённой причины и живой координатор после публикации. Для аварий использованы реальные фоновые задания с намеренным исключением. Проверены полный текст, сохранённые подробности, источник и счётчики трёх логических полос.
- 6 840 документов, 180 компонент: три разных захвата, отдельные полосы прогресса, следующий пакет выдан до завершения соседей; индекс сохранён до завершения третьего потребителя.
- 4 560 документов: прежний режим с двумя потребителями и независимой выдачей следующего пакета.
- Три сценария устаревшего плана и сопоставление текущего прогресса.
- Два публичных фоновых запуска по 1 000 документов: с прежними аргументами и с новым аргументом 3. В файловой базе оба используют одно удаление.
- Остановка во время пятисекундного обработчика: команда принята за 7 мс; текущая транзакция зафиксировала ровно 2 000 ключей, следующий ключ сохранён, повторного побочного эффекта нет, временные регистры очищены.
- Повторена 31 прежняя проверка очереди, смены ролей, разделения, сохранённого графа и остановки.

Всего выполнены 13 локальных протоколов. Проверки нескольких потребителей моделируют занятость и не воспроизводят три параллельные транзакции PostgreSQL.

## Серверная практика

На серверной базе ТОиР режим с тремя работниками удаления дал примерно 10% прироста скорости относительно двух. Это приблизительный результат сравнения прогонов на этой базе; подтверждённых результатов на других конфигурациях пока нет. Он оставлен опцией; два удаления работают по умолчанию.

Наблюдавшийся общий обрыв сопровождался почти полным использованием памяти сервера и резким освобождением памяти. По одному графику не установлены процесс, который завершился, и причина его завершения. Исправление диагностики не заявляется исправлением всех возможных серверных аварий.

## Анализ исходников

Доступный анализатор сообщает 58 замечаний в модуле заданий против прежних 56. Два новых предупреждения относятся к платформенным функциям представления ошибок, используемым для совместимости с конфигурациями без БСП. Прежние ошибки и ограничения анализатора сохранены; чистый статический результат не заявляется. Выполнены техническая проверка и проверка проектных стандартов изменения.

Механизм обфускации, размеры пакетов и проверки ссылок в этой версии не изменялись.

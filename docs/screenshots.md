# Скриншоты для публикации

Основные кадры для страницы проекта:

| Файл | Что должно быть видно |
|---|---|
| `01-truncation-result.png` | Завершённая обрезка ТОиР: дата границы, итог, количество зафиксированных записей, ошибки и время около 3 ч 15 мин |
| `02-truncation-running.png` | Активная обрезка: строка подготовки и строки удаления, этапы, счётчики и кнопка остановки |
| `03-obfuscation-rules.png` | Настройки обфускации: раскрытое дерево правил, разные виды объектов, категории и команды отметок/фильтра |
| `04-obfuscation-result.png` | Отдельное окно результата обфускации с понятными итогами |
| `05-obfuscated-data.png` | Справочник после обфускации: разные имена персонажей или организации с ООО/ЗАО/ОАО |

Дополнительно полезны:

- `06-excluded-users.png` — исключённые пользователи и связанные записи на демонстрационных данных.
- `07-history-cleanup.png` — выбор очистки истории, журнала и настроек.
- `08-tab-help.png` — встроенная справка одной из вкладок.

Для первого кадра нужен именно итог завершённого запуска. Скриншот активной операции не подтверждает её конечную длительность. Результат обфускации можно показать на файловой демонстрационной базе: для иллюстрации не нужен новый серверный запуск.

Снимайте средствами Windows, например **Win + Shift + S**, и сохраняйте **PNG** без пересылки со сжатием. Предпочтительно окно шириной 1 600–1 920 пикселей. Оставьте заголовки и подписи команд; уберите лишний рабочий стол. Реальные ФИО, адрес сервера, имя рабочей базы и другие служебные данные замените демонстрационными либо закройте до публикации.

Для обложки лучше использовать `01-truncation-result.png`. Если скриншоты добавляются после подготовки загрузочных порций, включите их в отдельную загрузку `docs/images/` и проверьте ссылки README.

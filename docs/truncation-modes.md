# Два режима обрезки

По умолчанию используется обычный режим. Ускоренный включается флажком **«Ускоренная обрезка (риск битых ссылок)»** и требует подтверждения.

| Действие | Обычный | Ускоренный |
|---|---|---|
| Построение каскада | Да | Да |
| Повторная проверка обычных входящих ссылок перед удалением | Да | Пропускается |
| Особые значения, журналы документов и сохранность остальных записей | Проверяются | Проверяются |
| Пересечения, транзакции и остановка | Сохраняются | Сохраняются |

Ускоренный режим может оставить битые ссылки. Точную универсальную вероятность для любой конфигурации определить нельзя. Выбранный режим сохраняется на весь запуск и недоступен для изменения во время работы.

В обоих режимах содержимое хранилищ значений и табличных документов автоматически не обходится. Отдельная сплошная проверка всей базы после удаления не выполняется.

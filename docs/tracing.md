# Трассировка

Трассировка помогает понять, на каком этапе тратится время. По умолчанию она выключена.

1. До запуска установите флажок **«Трассировка выполнения»**.
2. Запустите обрезку.
3. При необходимости нажмите **«Сохранить трассировку»** — во время работы или после завершения.
4. Выберите место для XML-файла.

В журнал записываются начала и окончания операций, длительность, технические идентификаторы, таблицы и объёмы. Прикладные значения параметров в трассировку не включаются. Это прикладные замеры, а не план запросов или полный журнал блокировок СУБД.

Для записи нужен информационный уровень журнала регистрации. Расширение не меняет настройки журнала автоматически.

Очистка временных регистров не удаляет трассировку из журнала регистрации. Последующее сокращение самого журнала может её удалить; сохраните нужный файл заранее. После диагностики снимите флажок перед следующим запуском.

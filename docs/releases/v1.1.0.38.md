# Cutter3000 1.1.0.38

Выпуск зафиксирован 24.10.2026. Обновление относительно публичной версии 1.1.0.24.

## Изменения

- После завершения конфликтовавших работ параллельная выдача восстанавливается; фактические пересечения продолжают проверяться.
- Сохранённые отложенные каскады проверяются и используются повторно; независимые компоненты можно выдать свободному работнику, оставив занятую часть в ожидании.
- Подготовка большого графа и остановка проверяются между порциями; для ограниченного размера графа применяется Union–Find.
- Служебный план упакован, опубликованное задание использует существующий индекс узлов без повторной полной копии.
- Сокращены повторные чтения по метаданным, загрузка связей выполняется пакетами, проверенные полные цели кешируются в пределах одной загрузки.
- Полные локаторы, контроль ссылок, целостность компонент и откат прикладного удаления сохранены.

## Проверки

26 регрессионных протоколов и 14 дополнительных контролей загрузчика. Нативная применимость и проверка модулей в четырёх контекстах на универсальном стенде и предоставленном CF ТОиР; проверка 66 XML и 24 текстовых файлов обратной выгрузки.

Для последнего изменения 1.1.0.37 → 1.1.0.38 медиана подготовки сохранённого графа на файловом стенде сократилась с 33,744 до 20,804 с — на 38,35%. Средняя сумма измеренных стадий уменьшилась с 77,798 до 67,029 с. Время публикации заметно колебалось; отсутствие замедления каждого соседнего этапа не доказано. Эти результаты не являются замером всей обрезки и не дают коэффициента ускорения серверной базы.

## Обновление

Дождитесь завершения текущей обрезки и её фоновых заданий. Обновите существующее расширение файлом Cutter3000.cfe и откройте новый сеанс 1С. Существующий выполняющийся вызов установкой нового CFE не изменяется.

Платформа от 8.3.26; управляемые формы; совместимость основной конфигурации от 8.3.14.

SHA-256: `81241F1FFDCAE7D2F9DD9D2FD80E19CD9A36E4456172AFB9479567C21DF2C427`.

# Cutter3000 v1.0.0

Расширение 1С для подготовки тестовых копий баз: удаление документов и периодических данных строго раньше выбранной даты с каскадным удалением обычных зависимостей.

- Порционные планы и карта ссылочных полей вместо предварительного индекса всей базы.
- Серверный конвейер: два читателя и до двух работников удаления; отложенная очередь пересекающихся порций.
- Прогресс, счетчик времени, таблица ошибок и подробности по двойному щелчку.
- Остановка с прекращением чтения, ожиданием текущих транзакций и очисткой четырех временных регистров. Результаты и ошибки сохраняются.

**Протестировано:** файловая база **8.3.27**; серверная **TopLog WMS / PostgreSQL, 8.3.26**. 
**Требования:** платформа от 8.3.26, совместимость основной конфигурации от 8.3.14, управляемые формы. БСП не требуется. Разделение данных не поддерживается.

Используйте тестовую копию без других писателей. Каскад может удалить более новые данные. Хранилища значений, табличные документы и СКД не обходятся; отдельный поиск входящих ссылок после удаления отключен.

Вложения релиза: `Cutter3000.cfe`, `SHA256SUMS.txt`, `Cutter3000-manifest.json`. Ревизия: `stop-icons-20261012`; версия метаданных: `1.0.0.0`.
